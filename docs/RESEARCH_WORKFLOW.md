# Research Workflow

The full research-to-paper workflow using ARIS Engineering Robotics.

## Stages

| # | Stage | Skill |
|---|---|---|
| 1 | Understand research question | research-pipeline-robotics |
| 2 | Select profile | robotics-research-router |
| 3 | Literature search | ARIS research-lit |
| 4 | Gap and novelty | ARIS novelty-check |
| 5 | Research refinement | ARIS research-refine |
| 6 | Define initial claims | ARIS claims-drafting |
| 7 | Design experiments | robotics-experiment-plan |
| 8 | Implement missing code | ARIS research-implement-feature |
| 9 | Run experiments | run-robotics-experiment |
| 10 | Monitor health | robotics-watchdog |
| 11 | Analyse results | robotics-result-analysis |
| 12 | Audit integrity | robotics-experiment-audit |
| 13 | Map results to claims | robotics-result-to-claim |
| 14 | Check evidence coverage | (pipeline decision node) |
| 15 | Additional experiments | (conditional) |
| 16 | Freeze evidence ledger | validate_evidence_ledger.py |
| 17 | Audit paper story | EPS engineering-paper-auditor |
| 18 | Write manuscript | EPS engineering-writing |
| 19 | Audit figures/tables | EPS engineering-figure-table |
| 20 | Polish | EPS engineering-polishing |
| 21 | Validate submission | EPS engineering-validation |

Use `research-pipeline-robotics` to orchestrate all stages with stopping criteria.
