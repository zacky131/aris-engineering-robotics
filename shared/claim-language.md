# Claim Language Reference

Quick reference for calibrating claim language.

## Verb selection guide

| Verb | When to use | Minimum evidence |
|---|---|---|
| is consistent with | Result does not contradict the mechanism | Any single result |
| suggests | Pattern present in limited data | N ≥ 1 controlled trial |
| indicates | Consistent pattern across trials | N ≥ 5 trials or conditions |
| supports | Consistent across multiple baselines/conditions | Multiple conditions |
| shows | Clear quantitative difference with statistics | N ≥ 10 with statistics |
| demonstrates | Repeated controlled experiment | Full reporting |
| confirms | Independent replication or cross-validation | Multiple independent datasets |

## Scope qualifiers (always include)

Always attach scope to a claim:
- Platform: "for the evaluated UAV configuration"
- Scenario: "under the tested maneuver-transition scenario"
- Conditions: "at wind speeds up to 2 m/s"
- Statistical: "across 20 simulation trials"
- Evidence: "in Gazebo simulation (L2)"

## Prohibited escalations

| From | Cannot escalate to |
|---|---|
| One scenario | "general" |
| Simulation | "real-world", "deployment" |
| Lab | "field operational" |
| Controlled | "arbitrary" |
| Tested range | "full envelope" |
