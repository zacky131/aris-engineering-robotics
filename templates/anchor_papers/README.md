# Anchor Papers

This directory holds research papers that serve as the starting point for
your ARIS Engineering Robotics research workflow.

Before the AI agent begins broad literature search, idea generation, or
experiment planning, it reads and analyses all papers placed here.

---

## Directory Layout

### Simple (flat)

```
anchor_papers/
├── paper1.pdf
├── paper2.pdf
└── paper3.pdf
```

All papers in the root directory are treated as `uncategorized`.

### Categorized

```
anchor_papers/
├── foundational/     → foundational theory and historical methods
├── closest_work/     → strongest novelty comparators (closest competitors)
├── methodology/      → experimental design, algorithms, metrics patterns
├── benchmark/        → baseline methods, datasets, evaluation protocols
└── uncategorized/    → no specific role assigned
```

**Category assignment is your organization — it does not imply the paper
is confirmed relevant.** The agent evaluates relevance independently.

---

## Privacy and Copyright

> Anchor PDFs are intentionally excluded from version control because they
> may be copyrighted, licensed for personal research use only, unpublished
> manuscripts, or otherwise private.

The `.gitignore` in this repository ignores all `*.pdf` files under `anchor_papers/`.

**Do not commit PDFs to a public repository.**

The following are tracked and safe to commit:
- `README.md` (this file)
- `.gitkeep` files (directory placeholders)
- Metadata generated by the framework (YAML records in `research/anchor_records/`)

---

## How to Add Papers

1. Place PDF files in the appropriate subdirectory.
2. Open your project in your AI coding agent (Codex, Claude Code, or Antigravity).
3. Use the anchor-paper-intake skill:
   ```
   Use the anchor-paper-intake skill to process my anchor papers.
   ```
4. The agent reads the PDFs, extracts structured information, and generates
   research artifacts in `research/`.

---

## Generated Outputs

After processing, find these files in `research/`:

| File | Purpose |
|---|---|
| `ANCHOR_MANIFEST.yaml` | PDF fingerprints and process status |
| `anchor_records/AP001.yaml` | Per-paper structured record |
| `ANCHOR_PAPER_INDEX.md` | Factual index and per-paper detail |
| `ANCHOR_PAPER_SYNTHESIS.md` | Cross-paper comparison matrix |
| `ANCHOR_GAP_HYPOTHESES.md` | Unverified gap hypotheses |
| `LITERATURE_SEARCH_PLAN.md` | Anchor-derived search directions |
| `RESEARCH_GAP_MAP.md` | Gap status tracker (updated by novelty-check) |

---

## Important Principle

Gap hypotheses derived from anchor papers are **UNVERIFIED** until independent
literature search confirms they are still open research problems.

An older anchor paper may describe a gap that has already been solved.
The agent will always verify gap status against current literature before
using it to justify a research contribution.
